# V2 Sports Hub assets

- `fonts/BarlowCondensed-Bold.ttf`: Barlow Condensed, Google Fonts; redistribution license in `fonts/OFL.txt`.
- `sports_world.json`: rounded coordinate-only exterior rings derived from Natural Earth's public-domain 1:110m country boundaries, excluding Antarctica. Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson.
- No scores or demonstration games are bundled. Native screens fetch the existing real Sports Hub API. Channel playback uses the signed-in user's existing guide bundle.
