# ON NOW TV V2 — Product requirements and current state

Updated: 2026-10-19. Historical implementation details previously in this 12,244-line file are preserved in [CHANGELOG.md](CHANGELOG.md). Priorities are in [ROADMAP.md](ROADMAP.md). Newest sections supersede earlier static18category/external-library/3D status and temporary test blockers.

## Original product requirements
Continue development of the ON NOW TV V2 app suite:
1. Polish Vesper Movies UI, layouts, navigation and native player interactions.
2. Build ON NOW Trivia as a standalone Android TV interactive party game.
3. Fix backend bugs and maintain the self-hosted launcher environment.
4. Sports Hub: premium native scoreboards/fields, exact fixture channels and automatic verified replay availability—no manual Check replay step.
5. Native sports navigation must open matches/teams promptly on low-end boxes, without a blank transition or blocking guide initialization; prominent loading bars/text and seed-first team information. User explicitly rejected 3D: detailed native 2D fields with real play-by-play instead.
6. Sports Hub must retain and open the same loaded live channels available in What's On Live; distinguish exact fixture matches from unconfirmed live-sport options and never fabricate replay availability.
7. Dedicated top-menu Replays library: faded sport artwork squares/rectangles for all sports, then available provider archive recordings; Android phone portrait and TV landscape parity.
